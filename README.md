## Project Overview

**HTML Learning Modules** is a structured web programming curriculum designed to teach modern HTML5 standards from foundational document anatomy to production-grade semantic layouts, accessibility, and interactive browser APIs. Organized across 18 progressive module directories, the repository provides 300 isolated, self-contained HTML submodules paired with module-level study guides (`README.md` inside each module) and 300 rendered PNG browser output captures (`output/*.png`). Every lesson focuses on a single markup concept with embedded presentation styling so learners can inspect clean code, open each file directly in any modern browser, and verify expected visual behavior immediately.

## Learning Objectives

The curriculum is designed to build practical fluency in standards-compliant HTML authoring and web document architecture through incremental hands-on exploration. By working through the modules, learners aim to develop the following capabilities:

- Construct valid HTML5 document skeletons using `<!DOCTYPE html>`, root metadata, global attributes, and proper element nesting.
- Format textual hierarchies, lists, hyperlinks, responsive images, and accessible data tables using semantic markup.
- Build interactive HTML forms equipped with native input types, grouping controls, and browser-level validation attributes.
- Structure full web interfaces with HTML5 semantic landmarks (`<header>`, `<main>`, `<article>`, `<section>`, `<aside>`, `<footer>`) and SEO metadata.
- Integrate native multimedia (`<audio>`, `<video>`, WebVTT captions), sandboxed `<iframe>` embeds, inline SVG graphics, and 2D `<canvas>` elements.
- Apply WAI-ARIA roles, keyboard navigation patterns, internationalization (`lang`, `dir`, `<bdi>`, `<ruby>`), Microdata, and modern HTML attributes (`popover`, `inert`, `<dialog>`, `<template>`, Custom Elements).
- Audit document quality, performance attributes, and security practices before assembling complete multi-page HTML projects.

## Learning Level & Approach

The repository follows a progressive, module-based self-study architecture that moves systematically from introductory syntax in Module 01 to multi-page capstone builds in Module 18. Each submodule isolates one HTML element, attribute, or architectural pattern inside a dedicated `.html` file accompanied by explanatory notes in its module `README.md` and a reference screenshot in `output/`.

## Learning Path & Curriculum

The curriculum advances across 18 sequential modules grouped from foundational document syntax to modern HTML specifications and applied capstone pages:

1. **Foundations & Text Structure (Modules 01–04):** Document anatomy, headings, text semantics, hyperlinks, and list structures.
2. **Visual Media, Tables & Forms (Modules 05–08):** Responsive imagery, structured data tables, form controls, and native validation.
3. **Semantics, Metadata & Embedded Media (Modules 09–12):** Semantic page landmarks, `<head>` SEO metadata, multimedia tracks, and sandboxed embeds.
4. **Accessibility, Graphics & Global Web Standards (Modules 13–15):** WAI-ARIA authoring, SVG/Canvas rendering, RTL/Unicode support, and Microdata.
5. **Modern HTML, Quality Audits & Practical Projects (Modules 16–18):** Popover/Dialog/Web Components features, validation/performance audits, and 10 real-world HTML projects.

No compilers, package managers, or external runtime dependencies are required to study and execute the HTML lessons. Learners only need a local copy of the repository and a standard web browser.

- **Required:** A modern standards-compliant web browser (Google Chrome, Mozilla Firefox, or Microsoft Edge).
- **Required:** A text or code editor (such as Visual Studio Code) to inspect and modify `.html` source files.
- **Optional (Recommended):** The **Live Server** extension in VS Code (or any local static HTTP server) when testing relative embeds, WebVTT caption tracks, and multi-page navigation in Modules 05, 11, 12, and 18.

```bash
git clone https://github.com/weztcy/HTML-Learning-Modules.git
cd "HTML-Learning-Modules"
```

## Code Execution & Usage

Every submodule is a standalone HTML file that can be opened directly in a browser or served via a local static server. Follow the steps below to explore a lesson and compare your browser output against the module's reference capture.

1. Open the target module directory and read its `README.md` to review learning objectives and per-submodule notes.
2. Open any `.html` file (for example, `module-01-pengenalan-html-dan-struktur-dokumen/01_hello_html.html`) directly in Google Chrome, Mozilla Firefox, or Microsoft Edge.
3. For modules referencing local `assets/` or `pages/` resources (Modules 05, 11, 12, and 18), open the repository in VS Code and launch **Live Server** on the target `.html` file so relative paths, `<track>` subtitles, and `<iframe>` embeds resolve over HTTP.
4. Compare the live browser render with the corresponding image inside that module's `output/` folder (for example, `module-01-pengenalan-html-dan-struktur-dokumen/output/01_hello_html.png`).

```bash
# Optional: launch a quick local static server from the repository root using Python
python -m http.server 8080
```
