Modul 5: Gambar dan Visual

69. Penggunaan Format Gambar

Menganalisis peruntukan format grafis SVG, WebP, AVIF, PNG, dan JPEG dalam web development.

Panduan Format Gambar Web Modern:

Format Kelebihan Penggunaan Terbaik
SVG Skalabilitas tanpa batas (vektor), ukuran sangat kecil Ikon, logo, ilustrasi antarmuka
WebP / AVIF Kompresi mutakhir (30-50% lebih hemat dibanding JPG) Foto katalog web modern
PNG Mendukung transparansi alpha berkualitas tinggi Grafik dengan latar belakang tembus pandang

Catatan Pembelajaran

Materi ini mendemonstrasikan konsep Penggunaan Format Gambar dalam HTML5. Amati struktur elemen, atribut yang diterapkan, dan bagaimana peramban me-render komponen tersebut secara visual.
