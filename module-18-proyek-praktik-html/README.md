# Modul 18: Proyek Praktik HTML

## Ringkasan Ruang Lingkup Materi
Modul ini membahas konsep dasar dan implementasi praktis seputar **Proyek Praktik HTML**. Setiap submodul dirancang secara terisolasi agar pembelajar dapat memahami konsep satu per satu secara fokus dan terstruktur.

## Tujuan Pembelajaran Modul
Setelah menyelesaikan modul ini, peserta didik diharapkan mampu memahami, mengimplementasikan, dan menguji komponen-komponen utama dalam lingkup proyek praktik html sesuai standar modern W3C.

## Pembahasan Setiap Submodul

### 1. Halaman Profil Pribadi

- **Tujuan Pembelajaran:** Mengintegrasikan semantic layout, foto avatar SVG, dan daftar tag keahlian.
- **Konsep Utama:** Profil pribadi menyatukan header representatif, biodata ringkas, tag badges, dan tautan kontak.
- **Penjelasan Source Code:** Menampilkan kartu profil pengembang lengkap dengan avatar inisial, ringkasan pengalaman, dan lencana keahlian.
- **Cara Menjalankan:** Buka file `291_personal_profile_project.html` secara langsung di peramban web (Google Chrome, Mozilla Firefox, atau Microsoft Edge), atau jalankan ekstensi Live Server pada VS Code.
- **Hasil yang Diharapkan:** Kartu profil modern berlatar header gelap elegan dengan avatar YS dan lencana keahlian biru.
- **Screenshot Hasil Eksekusi:**
